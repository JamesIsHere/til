# Staying oriented across multiple CLI agent sessions

Running several coding agents at once in a plain terminal (Codex, Claude
Code, Antigravity) means nothing visually distinguishes one session from
another the way a GUI or overlay would. Two small settings fix that:
color-coded tabs, and toast notifications for only the critical-path
agents.

## Color-code the tabs

Give each agent's tab its own color. When you are cycling between three
or four sessions, the color tells you which agent you are looking at
before you read a single line of output.

## Toast only the critical path

Set toast notifications for the one or two agents whose work everything
else is waiting on — not all of them. If every agent gets a toast you go
nuts; if only 1-2 push notifications, each toast actually means
something and keeps you focused.
